# Primitives Pack A

A collection of reusable 2D primitive textures for Unity prototyping and game development.

## Installation

Install through Unity Package Manager using the Git repository URL:

`https://github.com/YOUR_USERNAME/primitives-pack-a.git`

## Usage

Textures are available under:

`Packages/com.quantumcat.primitives-pack-a/Runtime/Textures/`

Use them with Unity SpriteRenderer, UI Image, or any other compatible texture-based component.
